## 2. Rè (Rub & Buzz)

- Cách đo: Pink 25–150 Hz cùng dạng sóng × 3 lượt (pink-rattle-2.0) + Chirp log 20→2000 Hz 3 s (chirp-rattle-1.0), thu Exclusive, phát Shared. App tự sinh tín hiệu, **không đọc WAV** trong `Assets/Audio` (chỉ sine 1 kHz cho tab Scope).
- Pink: tỷ lệ rè lặp lại (RC) = tương quan envelope 4–12 kHz giữa các lượt. Chirp: "đỉnh rè" = bump năng lượng trên 10·f so với xu hướng ±½ octave.
- Từ 2026-11-17: Pink tối đa −12 dBFS RMS (trên −18 = dạng sóng −18 nhân biên độ; hash ≤ −18 ghim trong `tools/PinkRubBuzzCheck/Program.cs` để line chuẩn ở trạm còn hiệu lực; mặc định vẫn −18). Chẩn đoán theo mức −30/−24/−18/−12: chọn mức cao hơn ngưỡng khởi phát của loa lỗi ~6 dB, loa tốt vẫn sạch, chưa nén.
- WAV `Assets/Audio/pink-rattle-25-150Hz-6s-44100Hz-minus18dBFS-RMS.wav` giống từng bit tín hiệu app (có check); file cũ `pink-rattle-30-80Hz-…` (full-band, ngẫu nhiên) đã xóa.
- Dữ liệu thật (cùng loại loa lỗi, **chưa có loa tốt nào**):

  | Bản thu         | Thực tế              | HF−nền      | RC        | Xung >nền+10 dB |
  | --------------- | -------------------- | ----------- | --------- | --------------- |
  | 06/11 live −18  | rè, tai xác nhận     | +2,1 dB     | 59,5 %    | ≈0 %            |
  | 06/11 −30       | dưới ngưỡng rè       | +0,6        | 1,8 %     | nhiễu lẻ        |
  | 14/11 −18       | xung nhẹ             | +5,8…6,0    | 71–81 %   | 5–13 %          |
  | 16/11 −24 → −12 | không xung → xung rõ | +1,4 → +4,7 | 27 → 76 % | 0 → 2–5 %       |

- Kết luận:
  - RC đo độ lặp lại và SNR, không đo mức rè (thêm nhiễu +20 dB: RC 81 % → 2 %). Ngưỡng tuyệt đối 15/30 % không tin được khi chưa có line chuẩn.

  - Chirp bỏ sót cao tần rộng 40–300 Hz vì chỉ bắt cộng hưởng hẹp; không sửa bằng cách hạ ngưỡng.
  - 16/11: xung khóa pha một phía mỗi chu kỳ bass, giảm dần qua các lượt, không nén → cơ khí/khí động. Bench 14/11 nén từ −15, bench 16/11 không nén tới −12.
